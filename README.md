# Turkey Travel Planner

移动端优先的土耳其旅行规划 PWA。当前版本不依赖 npm 或第三方服务，数据集中在 `data/trip-data.js`。

## 启动

```powershell
node server.mjs
```

浏览器打开 `http://localhost:4173`。手机预览时，让手机与电脑在同一网络，并使用电脑局域网 IP 加端口访问；安装到主屏幕需要通过 HTTPS 或 localhost 环境。

## 已实现

- 首页、行程、预订、指南四个底部导航。
- 2026-11-03 至 2026-11-10 日期切换与纵向时间线。
- 活动、航班、住宿、交通卡片展开；复杂交通展示分步换乘。
- 景点 Google Maps 搜索入口；地图不伪装为静态地图。
- 预订按全部 / 航班 / 住宿 / 接驳筛选。
- 已出票和已预订与待补订单、待核实路线分离显示。
- PWA manifest、service worker、轻量 localStorage 页面与日期偏好。
- 全量保留交接要求中的核心实体 ID：FLIGHT-001—009、HOTEL-001—003、ACT-001—019、TRANS-001—008、TRANS-010—026、PRICE-001—017；缺失的 TRANS-009 未补造。

## 数据说明

原始 `粘贴的文本 (1).txt` 数据包在当前工作区及附件目录中未找到，因此当前数据来自用户交接指令和提供的截图。缺失订单号、凭证、联系方式、部分地址、景点开放时间、门票、接驳时间等字段均明确标为待补充或待核实。
